# BTEC Level 3 IT — Unit 1: Information Technology Systems
## Analysis of Past Papers (2019–2025) and AAQ 2025 Spec (Issue 5, Nov 2025)

## Exam Structure
- **Total marks:** 90 marks
- **Duration:** 2 hours
- **Format:** 4 scenario-based questions (one extended scenario per question)
- **Each question:** ~22 marks total (one is usually 24), broken into sub-parts (a)–(f)
- **Sub-parts mix:**
  - 1 mark — State / name / give / identify
  - 2 marks — State + brief / Give two
  - 2 marks — Explain one (1 ID + 1 expansion)
  - 3 marks — Explain (1 ID + linked justification + further expansion)
  - 4 marks — Describe / Explain two (1 ID + 1 expansion × 2)
  - 6 marks — Discuss / Draw (flowchart, network diagram) — Levels-Based (L1: 1–2, L2: 3–4, L3: 5–6)
  - 8 marks — Discuss — Levels-Based (L1: 1–3, L2: 4–6, L3: 7–8)
  - 9 marks — Evaluate — Levels-Based (L1: 1–3, L2: 4–6, L3: 7–9), AO2/AO3a/AO3b
  - 12 marks — Evaluate (extended) — Levels-Based (L1: 1–4, L2: 5–8, L3: 9–12)

## Assessment Objectives
- **AO1** — Demonstrate knowledge and understanding (recall)
- **AO2** — Apply knowledge and understanding (to scenario)
- **AO3** — Analyse and evaluate (factors and implications)
  - AO3a — Analysis (breaking down)
  - AO3b — Evaluation (judgement supported by evidence, conclusion)

## Command Verb Conventions (per spec, p.34)
- **State / Name / Give** — recall one piece of info (1 mark each)
- **Identify** — select from stimulus (1 mark each)
- **Describe** — account / list of key features (1 mark per linked point, typically 4)
- **Explain** — point + linked justification/exemplification (1 ID + 1 expansion)
- **Discuss** — consider different aspects in detail and how they interrelate (Levels-based, 6 or 8)
- **Evaluate** — strengths/weaknesses, advantages/disadvantages, judgement with conclusion (Levels-based, 9 or 12)
- **Draw** — diagram or flowchart (Levels-based 6 marks)

## Mark Scheme Conventions
- **Short-answer questions:** "Award one mark for X up to a maximum of N marks"; bullet list of credit-worthy points; "Accept any other appropriate/alternative response"
- **Linked-explain questions:** "Award one mark for identification and one mark for an appropriate linked justification/expansion"
- **Levels-based questions:** Indicative content (not prescriptive) + Level descriptors (Level 0 = no rewardable material; ascending traits per AO)
- **Standard "Do not accept" lines** for common wrong answers

## Scenario Style
Scenarios are realistic UK businesses/contexts:
- Retail (online/in-store), schools/colleges, healthcare, leisure centres, garages, charities, financial services, manufacturing, accountants, photographers, sports/training, theatre/media, advertising, etc.
- Always includes a context paragraph + sub-questions referencing it
- Sub-questions step from low-mark recall → application → extended evaluation

## Learning Aims (AAQ 2025 Spec, Issue 5, Nov 2025) — Unit 1

### A: Explore the concepts and implications of the use of, and relationships among devices that form IT systems
- **A1 Functions and use of digital devices, and notation** — PCs, multifunctional, mobile, servers (file/app/web), entertainment, digital cameras (still/video), navigation, communication, embedded (sensors, IoT). Functions for: personal, education, social, retail, manufacturing, healthcare, creative, automation/robotics. Notation: network diagrams, flowcharts.
- **A2 Peripheral devices & media** — input/output/storage devices; assistive tech (adaptive keyboards, screen readers, braille, magnifiers, head pointers, single-switch, foot switches, sip-and-puff, eye-tracking, text-to-speech); storage characteristics (capacity/cost/speed/compatibility); manual vs automatic data processing.
- **A3 Computer software** — OS types (batch, distributed, multitasking, network OS, real-time, mobile, single-use, multi-user); OS roles (networking, security, memory mgmt, multi-tasking, device drivers, user accounts); utility vs application; factors (cost/security/compatibility/features/needs/performance); UI types (CLI, menu, GUI, touchscreen GUI); open-source vs proprietary; file types/formats (images/audio/videos/apps).
- **A4 Choosing IT systems** — Factors: user needs, specs, compatibility, connectivity, cost, efficiency, implementation (timescales/testing/migration/downtime), productivity, security. Uses: stock control, data logging, data analysis, office, creative, advertising, manufacturing, security, automation. Impact/implications: UX (ease/performance/availability/accessibility), employee/customer needs, cost, implementation, replacement/integration, productivity, working practices, training (initial/ongoing), user support, security.
- **A5 Emerging technologies** — concepts/implications of emerging tech & AI on performance, personal use, organisational use.

### B: Transmitting data
- **B1 Connectivity** — Bluetooth, USB, Wi-Fi, Ethernet; meeting needs; implications; impact on performance.
- **B2 Networks** — Topologies: star, ring, bus. Types: PAN, LAN, WAN, VPN. Choice factors (user needs/specs/connectivity/cost/efficiency/compatibility/implementation/productivity/security). Performance.
- **B3 Issues relating to transmission of data** — Protocols (email: SMTP, POP, IMAP; voice/video over internet; web: HTTP, HTTPS; secure payment); security issues; bandwidth & latency; file types/formats; compression (lossy/lossless); codecs.

### C: Operating online
- **C1 Online systems** — Cloud models (private/public/hybrid; IaaS/SaaS/PaaS); cloud impact/implications; remote working (VPN, remote desktop); selection factors (security/cost/ease/features/connectivity/scalability).
- **C2 Online communities** — social media, blog/vlog, wiki, chatrooms, IM, podcasts, forums; considerations (UX, user needs, cost, privacy, security, downtime, training, integration, productivity, working practices/policies).

### D: Protecting data and information
- **D1 Threats** — External (viruses/malware, hackers/unauthorised access, accidental damage, social engineering, natural disasters); Internal (inappropriate websites, accidental disclosure, stealing/leaking, portable devices). Impact (loss of data, financial loss, loss of customers).
- **D2 Protecting data** — File permissions, access levels, backup/recovery, passwords/MFA, biometrics, physical access control, digital certificates; antivirus; firewalls; encryption (stored, transmission, HTTPS).

### E: Impact of using IT systems
- **E1 Online services** — Retail, financial, education/training, news, entertainment/leisure, booking. Uses & impact: transactional data, targeted marketing, collaborative working, remote working.
- **E2 Using and manipulating data** — Sources (primary/secondary); reliability; collection methods (survey, questionnaire, focus groups, interview); data accuracy reasons & methods (verification, validation); UI characteristics (ease/accessibility/error reduction/functionality/performance/compatibility).

### F: Issues
- **F1 Moral/ethical** — Privacy, environmental impact, unequal access, access to assistive tech, online behaviour/netiquette, acceptable use policies.
- **F2 Legal** — Computer misuse legislation; copyright/designs/patents; copyright (computer programs); H&S/DSE regs; data protection legislation.

## Question Style Examples (for reproduction in generated questions)

### 1-mark "State"
"State one network topology the company could have installed."
Mark scheme: Award one mark for any one of: • Ring • Star

### 2-mark "Give two"
"Give two external threats to unsecured data."
Award one mark for each, max 2: viruses/malware (1), unauthorised access/hackers (1), social engineering (1).

### 2-mark "Explain one"
"Explain one way a VPN ensures any data accessed remotely is secure during transmission."
Award 1 ID + 1 expansion. e.g., "VPN uses encryption (1), so data is unreadable if intercepted (1)."

### 4-mark "Describe" (linked points)
"Describe the process used by a system to authenticate passwords."
Award 1 mark per linked point, max 4: database created (1); checked against username (1); access allowed if matches (1); re-enter if no match (1)…

### 4-mark "Explain two" (2 IDs + 2 expansions)
"Explain two validation methods the shop could use…"
Each: identification (1) + expansion (1).

### 6-mark "Discuss" — Levels-based
"Discuss the implications of the move to online-only sales for the mobile phone shop."
Indicative content + L1 (1–2)/L2 (3–4)/L3 (5–6) descriptors per AO2/AO3a.

### 6-mark "Draw flowchart"
"Draw a flowchart to show the process for the click-and-collect service."
Logic (max 4) + annotation (max 2): start/stop, decisions with Yes/No, accurate symbols.

### 9-mark "Evaluate" — Levels-based AO2/AO3a/AO3b
"Evaluate the cost implications for the retail company of a move to cloud computing.
You should consider: • Benefits • Drawbacks."

### 12-mark "Evaluate" (one per paper, larger)
"Evaluate the implications for the performance of IT systems and the use of IT systems by employees."

## Generation Mix per Learning Aim (target: 100 questions each = 600 total)
Roughly mirror the paper's distribution:
- 15 × 1-mark (state/give/identify)
- 20 × 2-mark (give two / explain one)
- 25 × 4-mark (describe / explain two)
- 10 × 3-mark (explain with two expansions)
- 15 × 6-mark Discuss (levels-based)
- 10 × 8-mark Discuss (levels-based)
- 4 × 9-mark Evaluate (levels-based)
- 1 × 12-mark Evaluate (levels-based)

This gives a strong distribution across AO1/AO2/AO3 and full command-verb range.
