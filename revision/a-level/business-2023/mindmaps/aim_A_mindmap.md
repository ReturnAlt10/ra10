# Learning Aim A Mindmap: IT Systems and Devices

## A1: Functions and Use of Digital Devices
- **Personal Computers**: Versatile, used for work, study, entertainment
  - *Advantages*: High performance, multitasking, upgradeable
  - *Disadvantages*: Bulky, higher cost, less portable
- **Multifunctional Devices**: Printers, scanners, copiers
  - *Advantages*: Space-saving, cost-effective
  - *Disadvantages*: If one function fails, all may be affected
- **Mobile Devices**: Smartphones, tablets
  - *Advantages*: Portable, always connected, apps
  - *Disadvantages*: Limited power, smaller screens
- **Servers**: File, application, web
  - *Advantages*: Centralized management, resource sharing
  - *Disadvantages*: Expensive, requires maintenance
- **Entertainment Systems**: Consoles, smart TVs
- **Digital Cameras**: Still, video
- **Navigation Systems**: GPS, satnav
- **Communication Devices/Systems**: Routers, modems
- **Embedded Systems**: IoT, sensors

### Uses
- Personal, education, social, retail, manufacturing, healthcare, creative, automation

## A1.3: Notation in IT Systems
- **Network Diagrams**: Show device connections
- **Flowcharts**: Show processes, logic

## A2: Peripheral Devices and Media
- **Input**: Keyboard, mouse, scanner
- **Output**: Monitor, printer
- **Storage**: HDD, SSD, USB
- **Assistive Tech**: Adaptive keyboards, screen readers, braille displays
- **Media Characteristics**: Capacity, cost, speed, compatibility
- **Data Processing**: Manual vs. automatic

## A3: Computer Software
- **Operating Systems**: Batch, distributed, multitasking, network, real-time, mobile, single/multi-user
- **OS Roles**: Networking, security, memory, multitasking, drivers, user accounts
- **Software Types**: Utility, application
- **Choice Factors**: Cost, security, compatibility, features, needs, performance
- **User Interfaces**: CLI, menu, GUI, touchscreen
- **Open Source vs Proprietary**
- **File Types**: Images, audio, video, app files

## A4: Choosing IT Systems
- **Factors**: User needs, specs, compatibility, connectivity, cost, efficiency, implementation, productivity, security
- **Organisational Use**: Stock control, data logging, analysis, office, creative, advertising, manufacturing, security, automation
- **Impacts**: User experience, cost, implementation, productivity, training, support, security

## A5: Emerging Technologies
- **AI, IoT, new tech**: Impact on performance, personal/organisational use

- Know notation symbols
