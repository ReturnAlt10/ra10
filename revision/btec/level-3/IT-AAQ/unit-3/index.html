  • Task-by-task walkthroughs — exactly what to produce for Pass, Merit and Distinction

How this unit is structured

Learning Aims & assignments

This is an internal unit assessed by a Pearson Set Assignment (3 tasks). The theory in Part 1 feeds directly into the tasks in Part 2.

Revise

Knowledge-check questions only — not exam questions. Pick a mode below.

Wireframe Designer

Drag blocks onto the canvas to sketch each page layout. Add annotation notes, then export your wireframe as evidence.

Sitemap Builder

Plan every page of your site and how they link together. Add annotations to show how the structure meets the client brief.

Code Editor

Write real HTML, CSS and JavaScript with a live preview. Cloud autosave keeps your project safe — or connect a local folder (like VS Code / Dreamweaver) to work on files already on your computer.

Assignment Hub

Step-by-step support for all three tasks — walkthroughs, sample briefs, and AI Assigner marking of your own work.

AI Assigner

Your personal mentor for Unit 3. Ask for hints on theory, help with a task, or upload your assignment for marking. It never writes your work for you — it coaches you to do it yourself.
