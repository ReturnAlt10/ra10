# Learning Aim B Mindmap: Transmitting Data

## B1: Connectivity
- **Wired**: USB, Ethernet
  - *Advantages*: Reliable, fast, secure
  - *Disadvantages*: Less portable, cable management
- **Wireless**: Bluetooth, Wi-Fi
  - *Advantages*: Portable, flexible
  - *Disadvantages*: Interference, security risks
- **Choosing Connections**: Needs, cost, efficiency, compatibility, security
- **Performance Impact**: Bandwidth, latency

## B2: Networks
- **Topologies**: Star, ring, bus
- **Types**: PAN, LAN, WAN, VPN
- **Choice Factors**: User needs, specs, connectivity, cost, efficiency, compatibility, implementation, productivity, security
- **Performance**: Network features/components affect IT system performance

## B3: Data Transmission Issues
- **Protocols**: Email (SMTP, POP, IMAP), Web (HTTP, HTTPS), VoIP, Secure payments
- **Security**: Encryption, firewalls, secure protocols
- **Bandwidth/Latency**: Affects speed, reliability
- **File Types**: Images, audio, video, app files
- **Compression**: Lossy vs. lossless
- **Codecs**: Audio/video transmission

### Exam Tips
- Compare wired vs wireless
- Draw/label topologies
- Explain protocol use
- Discuss security implications
